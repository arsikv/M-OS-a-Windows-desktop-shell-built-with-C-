## 🚀 Ключевые возможности Manyashka OS 1.0 Final

### 1. 🛡️ Автономность в один переносной файл (Zero-Dependency First Run)
* Файл `MPlusOS.exe` содержит в себе всю необходимую логику, векторные иконки и ресурсы.
* При запуске на новом компьютере с флешки:
  * Сам создает структуру папок `Data\Wallpapers`, `Data\CustomMusic`, `Data\Screenshots`, `Data\Machines`.
  * Автоматически считывает текущие обои пользователя из Windows и выставляет их на рабочий стол.
  * При отсутствии шрифтов Inter на ПК автоматически и бесшовно переключается на системный Segoe UI Variable без сбоев верстки.

### 2. 🗂️ Живая лента открытых окон в панели (TopBar Live Task Strip)
* Прямо в верхней системной панели в реальном времени отображаются открытые окна:  
  `[ 📁 Проводник ✕ ]` `[ 💻 Терминал ✕ ]` `[ 📝 Заметки ✕ ]` `[ 🌐 Браузер ✕ ]`.
* Все процессы перед глазами: один клик переключает на нужное окно, клик на `✕` мгновенно закрывает его.

### 3. 🪟 Умный сплит-экран (Window Snapping)
* Подтяните окно к левому краю экрана — оно примагнитится ровно на **50% экрана слева**.
* Подтяните окно к правому краю экрана — оно примагнитится ровно на **50% экрана справа**.
* Подтяните окно к верхней панели — оно развернется во весь экран.
* Горячие клавиши: `Win + ←` (левая половина), `Win + →` (правая половина), `Win + ↑` (развернуть), `Win + ↓` (свернуть).

### 4. 📸 Встроенный инструмент скриншотов (M+ ScreenCapture)
* Нажмите клавишу `PrtScn` (PrintScreen) или значок камеры в системном трее.
* Выделите мышью желаемую область экрана.
* Программа сделает снимок, автоматически сохранит его в формате PNG в `Data\Screenshots\` и скопирует в буфер обмена Windows для быстрой вставки (`Ctrl + V`).

### 5. 🔍 Умный пульт Spotlight с калькулятором (`Alt + Space`)
* **Мгновенный калькулятор:** введите математическое выражение (например, `2500 * 1.2 + 50`), нажмите Enter — и результат скопирован в буфер.
* **Быстрые системные команды:**
  * `скрин` / `shot` — моментальный запуск скриншотера.
  * `ram` / `чистка` — принудительная очистка и сжатие оперативной памяти.
  * `lock` / `блок` — переход на экран блокировки.
  * `код`, `терминал`, `проводник` — быстрый запуск инструментов.

### 6. 🗄️ Шкаф приложений (App Cabinet) с персональной полкой
* Верхняя полка шкафа — **«ЧАСТО ИСПОЛЬЗУЕМЫЕ»**.
* У каждого компьютера своя статистика благодаря аппаратному хэшу процессора и диска (`Data\Machines\<MID>_AppUsage.json`).
* Автоматический импорт всех ярлыков и программ с рабочего стола Windows в полку *«С рабочего стола Windows»*.

### 7. ⚡ Оптимизированный Dock
* Поддержка слабых встроенных видеокарт (Intel HD Graphics).
* В покое Dock потребляет 0% ресурсов видеочипа и процессора.

## ⌨️ Горячие клавиши Manyashka OS (Keyboard Shortcuts)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Win` | Открыть / закрыть «Шкаф приложений» (App Cabinet) |
| `Alt + Space` | Открыть командную строку и калькулятор Spotlight |

| `Win + L` | Заблокировать экран (Cozy Lock Screen) |

| `Win + →` | Примагнитить активное окно к правой половине экрана (50%) |
| `Win + ↑` | Развернуть активное окно на весь рабочий стол |
| `Win + ↓` | Свернуть окно |
| `Alt + Tab` | Переключение между последними активными окнами |
| `Esc` | Закрыть меню «Пуск», Шкаф, Spotlight или отменить скриншот |

## 🛠️ Сборка из исходников (Build Instructions)

Для пересборки `MPlusOS.exe` на компьютере должен быть установлен MinGW (GCC/G++) или MSVC:

1. Запустите командную строку в папке проекта.
2. Выполните:
   ```cmd
   build.bat
   ```
3. Скрипт скомпилирует ресурсы `resource.rc` с векторной иконкой приложения и создаст оптимизированный статический бинарник `MPlusOS.exe` (`-O2 -static`).
